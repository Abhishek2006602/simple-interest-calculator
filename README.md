# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user-provided principal amount, rate of interest, and time period.

## Formula

Simple Interest (SI) = (Principal × Rate × Time) / 100

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

You'll be prompted for:
- Principal amount
- Rate of interest (annual, %)
- Time period (years)

## Example

```
Enter principal amount: 10000
Enter rate of interest (%): 5
Enter time period (years): 2
Simple Interest: 1000.00
```
